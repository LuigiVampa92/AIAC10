## Вывод после просмотра агентом

С включённым max прямой способ уже решил 5/5 задач. Инструкция «решай пошагово»
не добавила правильных ответов, но увеличила расход с 3959 до 7200 токенов и время
с 37.731 до 66.199 с. Метапромптинг (3/5, 9965 токенов) и эксперты
(4/5, 6408 токенов) тоже не улучшили точность относительно прямого max.
В этой серии дополнительный промптинг при max не окупился по числу верных ответов.

Без reasoning ни один приём не превзошёл прямой способ: direct 2/5, steps 0/5,
meta 1/5, experts 2/5. В примере покупки итоговое поле ошибочно при правильном
объяснении; это ошибка конечного ответа по заранее установленному правилу, а не
ошибка парсинга. Один проход пяти задач не позволяет объявить приёмы бесполезными
вообще, но на этом наборе прямой max дал лучший результат по точности с меньшими
затратами, чем остальные способы с max. Оба этапа метапромптинга включены в расходы.
