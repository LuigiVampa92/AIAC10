## Структура

Основной файл дня — week_XX/day_YY/README.md: сам краткий отчёт,
в самом конце — ссылка на исходный JSON. Промежуточной страницы со ссылками нет.
В каталоге каждого прогона только week_XX/day_YY/runs/RUN_ID/raw.json.
Исходные JSON не редактируются, новые прогоны используют новые каталоги.
Краткий Markdown содержит таблицу, примеры, настройки и выводы.
Оставлена только актуальная серия каждого дня; старый отчёт и отдельные JSON
дня 2, а также неудачная попытка соединения дня 1 удалены по просьбе пользователя.
Дублирующих Markdown-отчётов в runs нет: единственный основной отчёт дня — README.md.

## Выгрузка из браузера

На страницах дней 1–5 кнопка «Скачать отчёт» формирует Markdown по текущим
результатам без дополнительных API-вызовов. Частичные серии помечены.
Браузер не записывает файл в репозиторий: пользователь сохраняет загрузку сам.
Автоматические наблюдения не заменяют содержательную оценку качества названий.
После обновления страницы или новой серии результаты могут быть утрачены;
отчёт нужно скачать заранее. Серверной БД и постоянной истории не добавлено.
