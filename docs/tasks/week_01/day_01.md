# Неделя 1 · День 1

**Статус:** условие получено; выполнение и проверка реальным API предстоят.

## Оригинальное условие
День 1. Первый запрос к LLM через API

Напишите минимальный код, который:

- 👉 отправляет запрос в LLM через API
- 👉 получает ответ
- 👉 выводит его в консоль или простой интерфейс (CLI / Web)

Результат:
Код, который отправляет запрос в LLM через API и получает ответ

## Критерии приёмки
Следующие проверяемые критерии выведены из оригинального условия:

- Пользователь вводит запрос на странице `/weeks/1/days/1` и отправляет форму.
- Приложение отправляет запрос в реальную LLM через API и получает ответ.
- Ответ отображается на той же странице в простом Web-интерфейсе.
- Демонстрационная заглушка не считается выполнением задания.

## Решение и проверка
В базовом проекте уже есть главная страница `/` с навигацией по всем неделям
и дням, страница первого дня с формой и общая граница вызова OpenAI API.
Модуль дня пока обозначен как техническая заготовка.

Дальнейшие шаги:

1. Адаптировать заготовку первого дня и подписи интерфейса под полученное условие.
2. Проверить lint, форматирование, типы и тесты без платных вызовов.
3. После согласования модели, бюджета и реального API-вызова проверить сценарий:
   главная → неделя 1 / день 1 → ввод запроса → отправка → ответ модели.
4. Зафиксировать результаты проверок и фактическую модель и параметры.

Реальный API в рамках этого задания ещё не проверялся. Задание не объявляется
выполненным до проверки пользовательского сценария с реальной моделью.

## Демонстрация
По `demo/checklist.md`: показать оригинал условия, открыть первый день с главной,
ввести запрос и показать ответ реальной модели, указать модель и фактически
отправленные параметры. Ключи и личные данные не должны попадать в кадр.

Commit и ссылка на видео будут добавлены пользователем после реализации и проверки.
