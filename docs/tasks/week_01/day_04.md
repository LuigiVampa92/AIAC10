## Оригинальное условие

🔥 День 4. Температура

Выполните запрос с параметрами:

- 👉 temperature = 0
- 👉 temperature = 0.7
- 👉 temperature = 1.2

Возьмите два типа запросов:

- 👉 задачу с одним правильным ответом
- 👉 задачу на генерацию (текст, идеи, варианты названий)

Каждую комбинацию прогоните 5 раз.

Сравните:

- 👉 насколько ответы отличаются между прогонами при одинаковых параметрах
- 👉 сколько раз сломался формат или ответ оказался неверным
- 👉 где разнообразие полезно, а где вредит

Сформулируйте:

- 👉 для каких задач лучше подходит каждая настройка
- 👉 даёт ли temperature = 0 одинаковый ответ каждый раз

Результат:

Примеры ответов с разной температурой и выводы по их использованию

## Критерии приёмки

Критерии ниже выведены из оригинального условия:

- Выбраны два запроса: с единственным правильным ответом и на генерацию.
- Каждая из трёх температур проверяется на каждом запросе пять раз: 30 ответов.
- Зафиксированы запросы, модель и остальные параметры для сопоставимости прогонов.
- Для каждой комбинации оценены различия ответов и число нарушений формата;
  для задачи с известным ответом также подсчитаны неверные ответы.
- Приведены примеры, выводы о применении температур и наблюдение о повторяемости
  при temperature = 0 без обещания гарантированной воспроизводимости.

## Решение и проверка

Это следующая задача после принятого пользователем дня 3 (2026-11-09).
Дни 1–3 выполнены; их сценарии сохранять рабочими. Приёмка дня 3 основана
на интерактивном сравнении, отдельный архив не требуется. Это не разрешение
на платные вызовы дня 4: запросы, модель и объём ещё предстоит согласовать.

Доступна только общая техническая форма. Эксперименты не реализованы и не запускались;
данных о разнообразии и ошибках пока нет. Demo не выполняет условия задания.

Следующий шаг — согласовать два запроса, формат, правила оценки и бюджет.
Выбрать модель и API, поддерживающие все три значения temperature; поддержку
проверить перед реализацией. Не отправлять параметр, если выбранная модель его не поддерживает.
