## Оригинальное условие

🔥 День 3. Разные способы рассуждения

Возьмите 5–10 задач с известным ответом
(логических, алгоритмических или аналитических)

Решите их через API четырьмя способами:

- 👉 получите прямой ответ без дополнительных инструкций
- 👉 добавьте в промпт инструкцию: «решай пошагово»
- 👉 попросите модель сначала составить промпт для решения задачи,
  а затем используйте его
- 👉 создайте в промпте группу экспертов
  (например: аналитик, инженер, критик)
  и получите решение от каждого

Прогоните все четыре способа при двух настройках рассуждения:

- 👉 с минимальным рассуждением (`reasoning.effort: low` / минимальный budget_tokens / отключено)
- 👉 с максимальным рассуждением

Сравните:

- 👉 сколько задач решено верно
- 👉 сколько токенов и времени ушло

Результат:
Таблица «способ × рассуждение → верных ответов / токены / время» + вывод, какие приёмы промптинга перестают что-либо давать, когда рассуждение включено

## Критерии приёмки

Критерии ниже выведены из оригинального условия:

- Подготовлены 5–10 задач с эталонными ответами и явными правилами оценки.
- Один набор задач проверяется всеми четырьмя способами при двух настройках
  рассуждения: всего восемь комбинаций для каждой задачи.
- Для способа с генерацией промпта сохраняются сгенерированный промпт и результат
  его последующего использования; для группы экспертов — решения каждого.
- Учитываются токены и время всех вызовов способа, включая подготовительный вызов.
- Представлена таблица «способ × рассуждение → верных ответов / токены / время»
  и вывод по фактическим результатам о пользе приёмов при включённом рассуждении.

## Решение и проверка

Реализованы пять фиксированных задач, версия набора **v2**:

| Задача | Усложнение | Эталон и независимая проверка |
| --- | --- | --- |
| Покупка | Корзина, две последовательные скидки, округление вверх и порог доставки | 5620 × 0,85 × 0,88 = 4203,76; округление до 4204, доставка 290; итог **4494**. Тест использует точные рациональные числа. |
| Строка | Каскадные удаления в cabbaabbacddceffegghhijkkji | **c**, 13 удалений; проверка стековым алгоритмом. |
| Граф | Ориентированные рёбра, обязательное посещение C | **12**, путь A→D→E→C→F→G; тест перебирает все простые пути через C. Положительные веса позволяют ограничиться простыми путями. |
| Расписание | Максимальная ценность вместо количества встреч | **32**: [1,4), [4,7), [7,9), [9,11), ценности 8+10+6+8; тест перебирает все 256 подмножеств. |
| Логика | Прежняя задача о вазе | **Анна**; перебор трёх возможных виновников. |

Пользователь сообщил, что исходная модель слишком легко решала первые четыре
задачи даже без reasoning. По его запросу эти четыре условия заменены, пятое
сохранено. Первоначальный прогон — пилот набора v1, без сохранённого архива;
не смешивать его с новой серией. Версия набора включена в план и результаты вызовов.
Модель, промптинг и лимиты прежние. Усложнение добавляет связанные шаги,
но не гарантирует разницы в точности; оценивать также фактические токены и время.

Условия и эталоны раскрываются на странице. Эталоны независимо проверяются кодом.
Они не передаются модели. Оценка сравнивает строковое поле answer в JSON,
игнорируя только регистр и пробелы по краям. Нечисловые формулировки вместо
числа, единицы измерения, невалидный JSON считаются неверным ответом.
Это одновременно проверка ответа и соблюдения простого формата; данное ограничение
нужно учитывать при выводах о качестве рассуждения.

Модель согласована пользователем: **gpt-6-luna**, Responses API,
reasoning.effort=none / max. Настройка применяется только к дню 3,
общая модель и .env не меняются. Поддержка и тарифы проверены по
[официальной документации](https://developers.openai.com/api/docs/models/gpt-6-luna).
Каждый вызов ограничен 16000 выходных токенов (включая внутренние reasoning-токены),
120 секундами; повторы отключены, store=false. Достаточность лимита для max
проверяется в каждом ответе: incomplete не засчитывается как правильное решение.
Пользовательские прогоны подтверждены; универсальная достаточность лимита не гарантируется.

Четыре способа: прямой ответ с общим контрактом JSON; пошаговый с кратким
объяснением; создание и применение промпта; аналитик, инженер и критик в одном
вызове. Для экспертов обязательны три непустых решения и общий answer;
оценивается общий итог. Скрытые внутренние рассуждения не запрашиваются.
Подготовительный промпт ограничен 6000 символами; пустой, обрезанный, отказанный
или слишком длинный результат не используется, скрытой замены нет.

Полная матрица: 40 решений, до 50 API-вызовов, без повторов.
Можно выбрать одну задачу, способ и режим. Серия последовательна;
остановка действует после текущего вызова, в том числе между этапами метапромптинга.
При API-ошибке или неизвестном сетевом исходе серия останавливается без повтора.
Таблица сохраняет знаменатель запланированных задач при остановке и ошибках.
Токены и время обоих этапов складываются; reasoning не прибавляется к output повторно.
Отсутствующие показатели остаются неизвестными. Время — сумма API-вызовов,
без браузерных пауз. Отдельные ответы и JSON запроса/ответа доступны в карточках.

По окончательному решению пользователя отдельное сохранение результатов не требуется
для приёмки дня 3: результатом служит интерактивное сравнение на странице.
Сейчас результаты живут только в памяти страницы до обновления или нового запуска;
экспорта, серверного архива и постоянной истории дня 3 нет.
