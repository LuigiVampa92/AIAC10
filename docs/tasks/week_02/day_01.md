## Оригинальное условие

🔥 **День 6. Первый агент**

**Реализуйте простого агента, который:**

- 👉 принимает запрос пользователя
- 👉 отправляет его в LLM через API
- 👉 получает ответ
- 👉 выводит результат в вашем интерфейсе

(простой чат, CLI или web, запросы через HTTP-клиент)

**Дайте агенту 2–3 простых инструмента:**

- 👉 опишите их схемой в запросе к модели
(например: текущее время, калькулятор, конвертер валют по зашитому курсу, поиск по списку задач в памяти, бросок кубика)
- 👉 каждый инструмент — обычная функция в несколько строк внутри вашего кода
- 👉 модель сама решает, какой инструмент вызвать и с какими аргументами
- 👉 ваш код выполняет вызов и возвращает результат обратно в модель
- 👉 модель формулирует финальный ответ пользователю

**Важно:**

- 👉 агент должен быть отдельной сущностью, а не просто один вызов API
- 👉 цикл «запрос → вызов инструмента → результат → ответ» повторяется, пока модель не перестанет запрашивать инструменты
- 👉 логика запроса, вызова инструментов и ответа инкапсулирована в агенте

**Проверьте:**

- 👉 запрос, который решается без инструментов
- 👉 запрос, который требует одного инструмента
- 👉 запрос, который требует двух инструментов подряд

**Результат:**

Агент, который сам вызывает инструменты и использует их результат в ответе

## Реализация

- `src/aiac/agents/simple.py`: отдельный SimpleAgent с полным циклом
  запрос → function_call → локальная функция → function_call_output → следующий
  запрос → финальный ответ. Выбор функций и аргументов делает модель.
- `src/aiac/agents/tools.py`: три функции, строгие JSON-схемы и локальная
  валидация аргументов. Передаются описания функций, не Python-код.
- `src/aiac/tasks/week_02/day_01.py`: контрольный запрос, конфигурация
  доступных инструментов, суммарные метрики и проверка JSON.
- `src/aiac/llm/reasoning.py`: общая граница Responses API.
- `POST /weeks/2/days/1/run`: один запрос браузера запускает весь цикл.
  API-вызовов модели внутри этого цикла может быть несколько.
- Шаблон и JS дня показывают форму и результаты; логика агента не находится в маршруте.

| Функция / имя в API | Поведение |
| --- | --- |
| calculate / calculator | Выражение с неотрицательными числами, скобками и только сложением. Decimal, ограниченный AST без eval/кода/переменных; до 200 символов, 60 AST-узлов, результат до 10¹². |
| fixed_exchange | USD/EUR/RUB; зашито 1 USD = 90 RUB и 1 EUR = 100 RUB. Сумма 0–1 млн, округление до копеек. Это учебные значения, не текущие котировки. |
| current_time | Показание локальных часов UTC или Europe/Moscow. |

Сами функции не обращаются в сеть. Модель через API решает, какую функцию вызвать;
после выполнения результат возвращается модели. Поэтому инструменты могут
увеличивать число API-вызовов, время и токены. Полностью локальный планировщик
и локальная модель не реализованы.

Модель — текущая AIAC_LLM_MODEL, провайдер openai, demo отклоняется.
Выбранные схемы передаются с tool_choice=auto, parallel_tool_calls=false.
История сохраняет порядок output items, call_id, аргументы и непрозрачные reasoning
items. store=false, include=reasoning.encrypted_content.
Контракт сверялся с [OpenAI Docs](https://developers.openai.com/api/docs/guides/function-calling).

Исправлена ошибка HTTP 400 `Unknown parameter: input[1].status`:
replay_input удаляет верхнеуровневый status из копии элементов, отправляемой
в следующий input. Сырая история и ответы API для диагностики не изменяются.
ID, call_id, данные reasoning и результаты инструментов не теряются.
Есть регрессия для status=null и status=completed.

## Принятый интерфейс и сценарий

На странице один редактируемый запрос: перевести отдельно 100 USD и 50 EUR
в рубли, сложить суммы и вернуть JSON с timestamp и amount_rub.
Курсы не подсказываются в запросе или инструкциях: численные значения находятся
в конвертере. Без него модель решает задачу самостоятельно и может выбрать иной курс.

Три крупных горизонтальных плашки «Вкл / Выкл» управляют доступными схемами.
Нажимается вся плашка, доступна клавиатура с видимым фокусом; на узком экране
есть перенос. Отключённая функция не исполняется даже при неожиданном вызове модели.

Ручная работа расположена сверху: ответ, статус, фактическая модель, полное время,
число API-обращений и суммарные input/output/total_tokens. Ниже — все шаги,
вызовы, аргументы, результаты, usage и раскрываемые request/response.
Данные выводятся как текст, не HTML. Шаги появляются после завершения цикла.

После разделителя — отдельный автопрогон: текущий текст со всеми инструментами,
затем тот же текст без инструментов. Результаты сохраняются в таблице в пределах
страницы; ручной запуск в неё не добавляется. Промежуточные наборы проверяются вручную.
При ошибке серия останавливается без автоматического повтора; частичный результат остаётся.

| Что сравниваем | Правило |
| --- | --- |
| JSON | Только синтаксическая валидность для любого завершённого ответа. NaN/Infinity и Markdown-обёртки не принимаются. Поля, сумма и точность времени не оцениваются. |
| Время | Полное время серверного цикла агента. |
| Токены | Сумма usage всех обращений, включая повторно отправленный контекст; reasoning не прибавляется к output второй раз. |
| API / функции | Отдельные колонки числа API-обращений и локальных вызовов. |
| Сводка пары | Отношение и абсолютная разница времени и total_tokens относительно варианта без инструментов. При разных моделях, ошибке или неизвестной метрике сравнение не рассчитывается. |

Неизвестная хотя бы на одном шаге токенная метрика — «нет данных», не ноль.
Известные частичные суммы остаются в JSON результата. У каждого автозапуска
раскрываются собственный ответ и шаги.

В обоих режимах timestamp запрашивается строкой UTC YYYY-MM-DDTHH:mm:ssZ.
При включённых часах модель должна использовать локальный инструмент.
При выключенных — дать самостоятельную приблизительную метку, без null и фразы
об отсутствии времени. Такая метка может существенно отличаться от реальности.
Сервер не подставляет время скрыто. Формат задан инструкцией, строгая схема
ответа не включена; фактическое соблюдение зависит от модели.

## Ограничения и проверки

Один запуск: до 6 API-обращений, до 5 локальных вызовов, до 4096 выходных токенов
и 30 с на обращение, 120 с на цикл. Контекст ограничен 60000 символами,
запрос — 4000. Автопара — до 12 API-обращений. Это предохранители, не тариф.
Новые инструменты на последнем шаге не исполняются.
Повтор call_id, отключённый инструмент и параллельные вызовы останавливают цикл.
Отказ, incomplete, пустой ответ, ошибка API и timeout не считаются успехом.
При timeout незавершённый шаг сохраняется как unknown, сетевых повторов нет.

- `.venv/bin/pytest`: 160 passed, 1 live skipped.

- Покрыты локальные функции, replay/call_id, последовательные вызовы, границы,
  обработка ошибок, метрики, маршруты, безопасный DOM и управление формой.
- Browser access host ранее был недоступен: агент визуально страницу не подтвердил.
