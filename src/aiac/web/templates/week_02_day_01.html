Выключенные функции не передаются модели. Курсы находятся внутри функции конвертации. В сравнении оцениваем валидность JSON и ресурсы; сумму и время в ответе не оцениваем.

Время: при включённом инструменте используются локальные часы; при выключенном отвечает сама модель через API приблизительной меткой. В обоих случаях формат timestamp — YYYY-MM-DDTHH:mm:ssZ. Без часов это предположение модели, оно может существенно отличаться от реального времени.

Один запуск: до 6 обращений к модели, до 4096 выходных токенов на обращение. Инструменты выполняются локально. Каждый запуск начинается заново, история между запусками пока не сохраняется.

Сравнение запусков


Время — полный цикл агента, токены — сумма usage всех обращений, включая повторно
отправленный контекст. Нет данных означает неполную метрику, а не нулевой расход.
Один прогон не доказывает устойчивого преимущества.


Один запрос пользователя запускает цикл агента. Модель через API выбирает
следующий инструмент, функция выполняется локально, её результат передаётся модели.
Поэтому инструменты могут увеличивать время и число токенов.


Запустите автосравнение, чтобы увидеть разницу ресурсов.
