Стоимость рассчитана по usage и справочнику тарифов Standard, это не выписка биллинга. Неизвестные метрики не заменяются нулём. Reasoning входит в выходные токены. Среднее время — только для полученных ответов; оно включает сеть и ожидание API.

Для reasoning-моделей используется low, для старых моделей параметр не отправляется. Фактическая настройка видна в итогах и запросах. low не гарантирует одинакового внутреннего объёма работы разных моделей. Роли назначаете вы, они не определяют автоматически мощность выбранной модели.
