6 сообщений — 3 пары. Window сохраняет в рабочей памяти только хвост; Facts добавляет к нему ключи и значения, обновляемые после каждого сообщения пользователя; Summary сжимает раннюю часть по порогу дня 9.

Смена стратегии создаёт новую ветку из текущего хвоста. Прежняя ветка сохраняется. Старые facts и summary в новую стратегию не переносятся; забытые сообщения не восстанавливаются. Журнал ходов служит только для просмотра и не отправляется модели.

Сравнение трёх стратегий

  
Используется сценарий дня 9: общий реальный диалог из 24 сообщений и 8 заранее
    заданных деталей. Он воспроизводится для каждой памяти. Window отбрасывает старое,
    Facts обновляется после каждого пользовательского сообщения, Summary сжимается по порогу.
    В конце всем задаются одинаковые вопросы без эталонных ответов.
