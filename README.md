# AIAC

Лаборатория челленджа: **7 недель × 5 дней**. Код создаётся AI-агентами.
Основа проекта набросана в OpenCode. Дальнейшая работа возможна в **Codex,
OpenCode и других системах**: проект не привязан к одному инструменту разработки.

Подготовлены 35 страниц-заготовок и общая интеграция с моделями. Получены условия
всех пяти дней первой недели — «Основы LLM»: первый API-запрос, формат ответа,
способы рассуждения, температура и версии моделей.
[Список заданий и статусы](docs/challenge.md#полученные-задания).
Реальные API-сценарии ещё не проверены; недели 2–7 ожидают условий.

## Быстрый вход в контекст для агента

1. Прочитать [AGENTS.md](AGENTS.md): границы работы и разрешения едины для всех систем.
2. Проверить `git status --short` и относящийся к задаче diff, сохранив существующие изменения.
3. Прочитать [описание челленджа](docs/challenge.md),
   [архитектуру](docs/architecture.md) и документ нужного дня.
4. Изучить модуль дня, затрагиваемые общие компоненты и тесты.

Оригиналы условий и актуальные статусы хранятся в документах дней.
Текущий фокус — неделя 1, день 1; следующий шаг описан в его документе.
При передаче работы другому агенту обновлять там результат, выполненные проверки,
ограничения и следующий шаг, чтобы продолжение не зависело от истории чата.

## Быстрый старт

Python 3.12 и uv. Если uv отсутствует, установить его локально, без глобальных изменений:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install uv
```

```sh
UV_CACHE_DIR=.cache/uv UV_PYTHON_DOWNLOADS=never .venv/bin/uv sync --inexact --frozen
.venv/bin/python -m uvicorn aiac.web.app:app --reload --host 127.0.0.1
```

Открыть http://127.0.0.1:8000. Активация venv не обязательна.
`--inexact` сохраняет локальный bootstrap uv, зависимости приложения закреплены в uv.lock.
В чистом окружении с глобальным uv можно использовать `uv sync --frozen`.

## Модели и оплата

По умолчанию работает **demo**, без API и расходов. Настройки читаются из окружения
или `.env` в корне. Пример — `.env.example`, настоящий `.env` в Git не попадает.

Реальный режим включается пользователем: `AIAC_LLM_MODE=openai`, отдельный
`OPENAI_API_KEY`, доступный API-аккаунту `AIAC_OPENAI_MODEL`.
Подписка или авторизация инструмента разработки не является API-ключом приложения.
**ChatGPT Plus не оплачивает OpenAI API.**
Агенты не должны самостоятельно включать платный режим или проверять его живыми вызовами.
Сервер только локальный; не публиковать без дополнительных мер защиты.

## Проверки

```sh
.venv/bin/ruff check .
.venv/bin/ruff format --check .
.venv/bin/mypy src
.venv/bin/pytest
```

Тесты не используют реальный API. OpenAI-интеграция проверяется подменой клиента.

## Навигация

- [Правила агентов](AGENTS.md), [условия](docs/challenge.md), [архитектура](docs/architecture.md).
- `docs/tasks/week_XX/day_YY.md` — условие и статус дня, источник описания в браузере.
- `src/aiac/tasks/week_XX/day_YY.py` — реализация дня.
- `src/aiac/web/`, `src/aiac/llm/` — общая оболочка и интеграция моделей.
- `demo/checklist.md` — памятка для записи видео.

Индекс, commit, push, remote и теги пользователь контролирует самостоятельно.
Фактическое состояние Git проверяется перед работой, а не выводится из этого описания.

`opencode.jsonc` относится только к OpenCode и не требуется для запуска приложения.
Он не настраивает разрешения Codex или других систем. При смене инструмента
правила проекта сохраняются; настройки доступа конкретной системы проверяются отдельно.
Проект не меняет глобальные настройки и выбранную пользователем модель разработки.
